# System: Merc Lab DMS

**For:** The Merc Lab · **Used by:** Kazumi's team (COO, Customer CRM, CFO, Technical) · **Built by:** Software Studio (George)

| | |
|---|---|
| Repository | [syakirbadry-tech/merclab-app](https://github.com/syakirbadry-tech/merclab-app) (public) |
| Live app | GitHub Pages, installable on a phone (see the repository's QUICK-DEPLOY.md for the address) |
| Stack | Progressive web app: one bundled `index.html`, `manifest.json`, `service-worker.js` for offline use |

## What it does today

The workshop's job and customer system: job cards, customers, vehicles, vehicle check-in, quotations, invoices, parts and inventory, and fault notes. Works offline after the first visit.
