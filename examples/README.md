# Examples

Reference project layouts showing how a real project repository should be structured when it's built on top of this engineering handbook. Each example is a `README.md` describing folder layout and which root-level standards apply — not runnable code.

| Example | Project Type |
|---|---|
| [OSH-C_PORTAL/](OSH-C_PORTAL/) | Customer/member portal web application |
| [WORKSHOP_SYSTEM/](WORKSHOP_SYSTEM/) | Workshop/event management system |
| [CRM_SYSTEM/](CRM_SYSTEM/) | Customer relationship management system |
| [QUOTATION_GENERATOR/](QUOTATION_GENERATOR/) | Quote/proposal generation system |
| [INVENTORY_SYSTEM/](INVENTORY_SYSTEM/) | Inventory and stock management system |

When starting a new project, copy the closest-matching example's structure, then adjust — don't design a new layout from scratch unless none of these fit.
